## ✨ The Idea

What can everyday habits tell us about student wellbeing?

**MindState** is a machine-learning project that explores this question through a web-based prediction system. It uses information about a student's lifestyle, academic routine, social-media habits, sleep, physical activity, and stress to estimate a numerical mental-health score.

The goal is simple: take a machine-learning model beyond a notebook and turn it into an interactive experience that people can explore online.

## 🔬 Under the Hood

MindState brings together data science, machine learning, and web development.

- **Data analysis:** Pandas, NumPy, Matplotlib, and Seaborn
- **Machine learning:** Scikit-learn, Linear Regression, and Random Forest Regression
- **Model pipeline:** Feature engineering, categorical encoding, numerical preprocessing, and model serialization
- **Backend:** FastAPI and Pydantic
- **Deployment:** Render
- **Version control:** Git and GitHub

The project follows an end-to-end workflow: data exploration → preprocessing → model training → evaluation → API integration → online deployment.

## 🎯 Why I Built It

MindState represents that step toward building practical, accessible ML-powered products.

## ⚠️ A Note on Responsible Use

MindState is an **educational machine-learning project**, not a medical or psychological diagnostic tool.

Its output is a model-generated estimate based on the dataset used for training. It should not be interpreted as a clinical assessment, and it cannot replace professional mental-health support.
